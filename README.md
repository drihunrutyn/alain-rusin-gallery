# Alain Rusin — витрина GitHub Pages и кабинет Render

Существующий стек сохранён: Bun, Vite, React, Hono, Drizzle, Turso, Tigris S3. Ветка `github-pages` — статическая витрина; `main` — существующий сервер Render с точечно добавленными сериями и видео. Ветки не следует сливать целиком.

## Адреса
- Витрина: https://drihunrutyn.github.io/alain-rusin-gallery/
- Кабинет: https://alain-rusin.onrender.com/admin/login
- Репозиторий: https://github.com/drihunrutyn/alain-rusin-gallery

## Обновления витрины
Workflow `.github/workflows/deploy-pages.yml` находится в обеих ветках; запуск на `main` всегда читает исходники `github-pages`.
- Расписание: **10:00, 13:00, 16:00, 19:00 Москва** (`0 7,10,13,16 * * *` UTC).
- Ручной запуск: Actions → Deploy static storefront → Run workflow → `main`.
- Push в `main` также запускает проверку/публикацию; push только в `github-pages` требует ручного запуска или ожидания расписания.
- Сохранение в кабинете не вызывает Actions. Данные сохраняются сразу в Turso, витрина обновляется в ближайшем окне.
- SHA256 публичного снимка не включает время сборки. Ключ кеша учитывает дерево исходников. При совпадении build/deploy пропускаются. Кеш сохраняется **только после успешного deployment**. Запуски последовательные.
- GitHub может задерживать scheduled jobs; точное время завершения не гарантируется.

## Возможности
- Серии из БД: название/описание, неизменяемый slug, порядок, обложка, архив. Непустую серию нельзя удалить напрямую: доступны архивирование или транзакционный перенос работ в другую активную серию и удаление. Архив скрывает серию и её работы из публичного каталога/PDF, не удаляя данные.
- Видео: YouTube, VK/VKVideo, Drive, Rutube, Vimeo, OK, прямые видеофайлы. Исходный URL сохраняется; безопасные неизвестные HTTP(S)-ссылки открываются отдельно. Автообложки YouTube/Drive или пользовательская обложка. Доступность плеера зависит от платформы и прав доступа ролика.
- PDF: доступные работы с актуальными названиями и порядком серий, кириллическими шрифтами и контактами.
- Политика владельца опубликована дословно, дата: **5 ноября 2026 года**. Согласие: «Согласен(на) на обработку персональных данных в целях ответа на мою заявку.»

## Данные и безопасность
Статическая сборка читает только публичные работы, контент, комнаты, активные серии и настройки `email`/`city`. Заявки, подписчики, просмотры, пароли и токены не экспортируются. `/admin` и `/api` в `out/` отсутствуют. Подписка и просмотры витрины продолжают обращаться к Render.

На Pages кнопки обращения открывают почтовый клиент/VK; сообщение отправляет сам посетитель. Render сохраняет своё существующее поведение заявок, подписок, статистики, авторизации и S3. Его публичные маршруты остаются доступны — переключение на редиректы не проводилось.

Секреты — только в корневой игнорируемой `.env` и защищённых настройках сервисов. GitHub PAT не нужен workflow и не попадает в репозиторий или браузер. Существующие сервер, auth, Dockerfile и S3-настройки не заменялись.

## Проверки и сборка
```sh
bun install --frozen-lockfile
bun run test:static
bun run lint
bun run build:admin
bun run build
```
Статическая сборка требует действующие `DATABASE_URL` и read-only `DATABASE_AUTH_TOKEN`; без базы падает, не подставляя тестовые данные. `--snapshot-only` готовит снимок/hash; `--from-snapshot` собирает уже проверенный снимок. PDF загружается лениво; предупреждение Vite о крупном PDF-чанке не является ошибкой.

Миграция и откат: [DEPLOYMENT.md](DEPLOYMENT.md). Не запускайте `db:push`, seed или очистку над действующей базой ради этой доработки.

## Редакционные ограничения
**Текст политики противоречит действующим функциям:** подписка отправляет email на Render/Turso, сервер хранит заявки, статистика и внешние плееры обращаются к сторонним сервисам. Владелец выбрал дословную публикацию без отключения функций. Это не юридически проверенная политика; для устранения противоречия нужна отдельная согласованная правка текста или функциональности.

Часть исходных изображений — фрагменты предоставленного триптиха, не подтверждённые фотографии всех оригиналов. Перед продажей загрузите оригинальные фотографии. Награды и членство — сведения владельца, без независимой проверки. `supabase/schema.sql` — историческое приложение, не действующая БД.
