# Alain Rusin — тёмный музей

Утверждено: веб-галерея на Bun / Vite / React / Hono, приватный GitHub и полная серверная версия на Render Free. Внешняя Turso SQLite и Tigris сохраняют данные вне непостоянного диска Render.

## Дизайн
- Фон #0F0F0F; поверхности #161616 и #1C1C1C; границы #2A2A2A.
- Текст #EDEAE4; вторичный #A6A29B; бронза #B8996F; ультрамарин #2A3B5C.
- Cormorant Garamond — заголовки, Manrope — интерфейс. Локальные TTF с кириллицей.
- Музейный простор, тонкие бронзовые линии, прямоугольные кнопки, никаких ярких CTA.
- Асимметричный первый экран: крупная типографика слева, триптих справа. Под ним статус премии, четыре серии, выбранные работы, художник, Артхив.
- Карточки работ 4:5, object-fit:contain, мягкие ореолы музейных софитов. Картины не генерируются.
- Адаптивная навигация, доступные формы, focus-visible, prefers-reduced-motion.
- Только копи-дек и заданные цены. Дополнительные подписи исключительно технические.

## Данные и страницы
Главная, каталог с фильтрами, работа с запросом и примеркой, о художнике, пресса/выставки, B2B, privacy, 404. Кабинет: дашборд, работы, заявки, четыре типа контента, настройки.
Таблицы: artworks, requests, content, subscribers, page_views, admin_settings, rooms. Приватные операции проверяют сессию на сервере. Логин и пароль из env; смена пароля сохраняет хешированный override, подпись сессии jose.
PDF: кремовая бумага, локальные шрифты, доступные работы по сериям, QR на сайт. Примерка: три CSS-сцены и загруженные фотографии интерьеров.

## Ассеты
Предоставлены морской этюд, триптих, баннер Артхива и логотип. Отдельных фото остальных трёх сид-работ нет. Фрагменты триптиха используются как предварительные иллюстрации серий, не как подтверждённые фотографии оригиналов; оговорка фиксируется в README.
